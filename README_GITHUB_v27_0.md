# みん会TCG Simulator Ver27.0 GitHub更新用

## 更新方法

このZIP内の `index.html` を、
GitHubリポジトリ `min-kai-tcg-simulator` のルートにある
`index.html` へ上書きしてください。

Supabase側の追加作業はありません。

## Ver27.0の変更

設定画面をカテゴリ別に整理しました。

- 表示
- 盤面
- オンライン
- 公開所
- アカウント・バックアップ
- ヘルプ
- 診断・メンテナンス

ヘルプには、カード登録・カード管理・デッキ作成・盤面・オンライン・公開所・セット配布・バックアップ等の説明を個別項目として追加しています。

診断・メンテナンスには「一時キャッシュを再構築」を追加しました。

### キャッシュ再構築で削除しないもの

- 登録カード
- デッキ
- コレクション
- カード画像
- アカウント情報
- クラウドバックアップ

### 削除対象になり得るもの

- オンライン対戦の一時スクロール位置
- 再接続用の一時盤面キャッシュ
- 一時的な検索 / 表示キャッシュ
- Simulator関連のブラウザキャッシュ

進行中のオンライン対戦では実行しないでください。

## Supabase

Ver27.0では変更ありません。
Ver26.7までに導入した公開所 / セット配布のSupabase設定をそのまま使用できます。
