# BUILD LAB v0.30

BUILD LABは、レベル上げや素材収集の縦成長ではなく、無料で組み替えられる横方向のビルド研究を中心にした実験型ゲームです。

## v0.27〜v0.30の主な追加
- アルカナ・ルーン・元素・連結・特殊個体・複合挙動をまたぐ横断ビルドを追加。
- 条件負荷監査を導入し、高条件カード/遺物/プロトコル/調律の報酬を再調整。
- 敵の特殊個体・複合挙動によって効果そのものが変わる解析カードを追加。
- 条件達成で変化する二面カードを16種へ拡張。
- カード実体ごとに段階を保持する3段階成長カード6種を追加。
- 複合解析カード6種を追加。敵特性の組み合わせで効果形状が分岐。
- 成長支援遺物・プロトコル・調律を追加。
