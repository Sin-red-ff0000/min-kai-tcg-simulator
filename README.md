# BUILD LAB v0.26

BUILD LABは、レベル上げや素材の縦成長ではなく、無料で組み替えられる横方向のビルド研究を中心にした実験型ゲームです。

## v0.26の主な追加
- 大アルカナ22枚（0 愚者〜21 世界）
- 条件達成で自動変化する二面カード8種
- 元素・錬成カード30種を含む大規模横拡張
- 特殊個体図鑑の発見条件常時表示
- 元素/錬成と既存の調律・ルーン・連結・アルカナをつなぐ新規ビルド
