# みん会TCG Simulator v16.24

v16.24はクラウド選択同期の安全性修正版です。

クラウドから端末へカード・デッキを選択同期する際、復元前の端末バックアップを保存できなかった場合でも同期処理が続行してしまう問題を修正しました。v16.24ではバックアップ保存結果を確認し、失敗した場合は端末データを書き換えずに同期を中止します。

アカウント・クラウド管理、最大5世代のクラウド履歴、選択同期、完全バックアップ、画像・外観バックアップなどv16.23までの機能は維持しています。

Supabase側の追加変更はありません。v16.22用Storageセットアップを適用済みなら追加SQLは不要です。
