みん会TCG Simulator Ver 25.5

オンライン再接続時に盤面が対戦開始時へ戻る問題を修正。

原因
- 再接続するとオンライン盤面オブジェクトは作り直される。
- 従来の onlinePrepareDuelBoard() は、相手側の公開盤面だけ room.publicState から復元していた。
- 自分側のキャラクター / 墓地 / 消失 / ペイン / ルーム / ルールプラスは makePlayer() の初期配置のまま残っていた。
- 手札だけは専用のローカル復元処理があったため、手札だけ正常に見えていた。

修正
- 再接続時はP1/P2両方の公開盤面を現在の room.publicState から復元。
- 自分側もキャラクター / 墓地 / 消失 / ペイン / ルーム / ルールプラスを復元。
- 手札は従来通り所有者専用復元を使用。
- デッキ順は従来通りサーバー管理のまま。
- 自分の公開盤面を端末にも補助キャッシュし、再接続時にサーバー側公開盤面が一時的に空の場合だけフォールバック。
- 復元直後に初期配置を誤って再送しないよう同期スナップショットを初期化。
- Ver25.4のスマホスクロール位置修正も含む。

Supabase Edge Function / SQL の変更は不要。
GitHubの index.html のみ上書きしてください。
