みん会TCG Simulator Ver 26.4

オンライン対戦で相手側のデッキ枚数が0枚固定になる問題と、
観戦時にデッキ枚数が0枚で表示される問題を修正しました。

原因
- 相手・観戦者にはデッキのカード内容や順番を渡さない仕様なので、ローカル上の相手デッキ本体は空です。
- その状態で表示側がローカルのデッキを参照すると0枚になっていました。
- room.p1 / room.p2 の deckCount は接続ロールによって相手・観戦者側で取れない場合がありました。

Ver26.4の変更
- デッキのカード内容・カードID・順番は今まで通り非公開。
- 残り枚数だけを publicState.p1/p2.meta.deckCount として公開盤面に保存。
- 相手プレイヤーと観戦者は、その公開残り枚数を使ってデッキ枚数を表示。
- サーバーから room.p1/p2.deckCount が取得できる場合はそれを最優先。
- publicStateのdeckCountを第2候補として使用。
- 旧ルーム互換としてdeckTotalを最終フォールバックに残しています。
- 相手公開盤面を端末へ反映する際にも表示用のdeckCountを保持。
- プレイヤー名横、デッキゾーン、オンラインツールバーの枚数表示を同じ取得方式へ統一。
- 公開盤面同期リクエストにもdeckCountを追加。
- 手札枚数についてもpublicState metaへ保存されるため、観戦表示の耐性を上げています。

既存の進行中ルーム
- Ver26.4のプレイヤーが公開盤面同期を1回行うと、その時点のdeckCountが公開盤面へ入ります。
- 新規対戦では開始時から残り枚数が入ります。

Supabase SQL / Edge Functionの必須変更はありません。
GitHubの index.html を上書きしてください。
