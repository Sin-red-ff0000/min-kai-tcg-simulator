みん会TCG Simulator Ver 25.9

オンライン対戦で、裏向きのペインカウントを手札へ戻した際に
「裏向きカード」のまま正体不明カードになる問題を修正。

原因
- オンラインでは裏向きの公開ゾーンカードを相手へ送る際、
  カードID・名称・効果などを消して「裏向きカード」に匿名化している。
- Ver25.5以降の再接続復元では、自分側の盤面もその公開用スナップショットから
  復元する場合があり、裏向きPCの本来のカード情報まで失われていた。
- その状態でPC→手札へ戻すと、表向きにはなるが内容は
  「裏向きカード / Lv - / PW -」の匿名データのままになっていた。

修正
- 自分側の公開ゾーンについて、相手用の公開データとは別に
  所有者専用の完全な盤面キャッシュを新設。
- キャラクター / 墓地 / 消失 / ペイン / ルーム / ルールプラスを
  カードID・名称・効果・裏表・カウンター等を保持したまま端末保存。
- 再接続時、自分側は所有者専用キャッシュを最優先で復元。
- 相手側には従来通り匿名化した公開情報だけを使用。
- 裏向きPC→手札など表向きになる移動時に、匿名カードだった場合は
  所有者専用キャッシュから元カードを復元してから表向きにする防御処理を追加。
- 手札・公開盤面を描画時 / 自動同期前 / ページ離脱時に保存。
- Ver25.8までの修正をすべて含む。

注意
- Ver25.8以前ですでに「裏向きカード」として正体情報を失った既存ルームについては、
  その端末にも元情報が残っていない場合、自動でカード名を特定することはできません。
- Ver25.9適用後に新しく置いた裏向きPCからは、この問題が起きないようにしています。

Supabase側の変更はありません。
GitHubの index.html を上書きしてください。
