みん会TCG Simulator v24.6 公開所 検索・一括操作改修 rev4

GitHub側
- 登録所の検索性をカード管理画面相当へ強化
  カード名 / 種類 / その他種類 / Lv / 種族 / レアリティ / 効果文 / 並び順
- 公開所も同等の検索条件へ強化
- 登録所を30件ごとのページ制へ変更
- 登録一覧はカード名 + カードタイプのみ表示。効果文は一覧に出さない
- 登録所にページ全選択 / 選択解除 / まとめて公開
- 公開所にページ全選択 / 選択解除 / まとめてダウンロード
- 登録所・公開所ともページ移動とページ番号指定に対応
- 登録前プレビューは従来通り右側で確認可能

一括公開
- 選択したカードへ現在入力中の作者名・ひとことを共通適用
- 画像は従来どおり公開しない

一括ダウンロード
- 選択した公開カードをまとめて登録
- 一括処理では同名カードがあっても別カードとして追加
  個別ダウンロードでは従来どおり同名時に選択肢を表示

Supabase側
