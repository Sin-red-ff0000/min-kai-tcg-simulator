# みん会TCG Simulator Ver27.1 GitHub更新用

## 必ずアップロードするファイル

Ver27.1からGitHub側は `index.html` だけではなく、次の3ファイルをリポジトリのルートへ配置してください。

- `index.html`
- `sw.js`
- `manifest.webmanifest`

既存の `index.html` は上書きしてください。
`sw.js` と `manifest.webmanifest` は新規追加です。

Supabase側の追加変更はありません。

## Ver27.1の主な変更

### カード登録の下書き自動保存

1枚ずつ登録で入力している内容を端末内へ自動保存します。

保存対象：
- カード名
- ルビ
- カード種類
- Lv
- POWER
- 種族
- レアリティ
- 効果
- フレーバーテキスト

画像ファイル本体はブラウザの仕様上、自動復元できません。
画像選択済みだった場合は復元時に再選択が必要です。

### デッキ編集途中の自動保存

デッキを正式保存する前の編集内容も端末内へ保存します。

ページを閉じたり、スマホブラウザが終了した後でも
「編集途中へ戻る」から復元できます。

また、デッキ作成画面の

- 検索文字
- カード種類
- 種族
- Lv / POWER範囲
- 並び順
- 詳細フィルターの開閉
- ページ番号
- スクロール位置

を保持します。

### オフライン利用

Ver27.1ではService Workerを追加しました。

一度オンライン状態でVer27.1を開くと、アプリ本体がブラウザへ保存されます。
その後は通信がない状態でも、端末内データを使う機能を起動できます。

オフライン利用可能な主な機能：
- カード登録
- カード管理
- デッキ作成
- コレクション
- ローカル設定

通信が必要：
- オンライン対戦
- 公開所
- セット配布
- アカウントのクラウド保存 / 復元

## GitHub Pages更新後の確認

Service Workerはブラウザに旧版が残ることがあります。

更新後、
1. Ver27.1と表示されることを確認
2. 一度ページを再読み込み
3. 必要ならブラウザを閉じて再度開く

を行ってください。

Simulatorの「診断・メンテナンス → 一時キャッシュを再構築」を使うとService Worker系キャッシュも削除される場合があります。その場合はオンライン状態で再読み込みしてください。

## Supabase

Ver27.1で追加作業はありません。
Ver26.7までに設定した公開所 / セット配布のSupabase構成をそのまま利用できます。
