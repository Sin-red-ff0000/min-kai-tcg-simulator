みん会TCG Simulator Ver 26.3

「らくらく復元」および完全バックアップ復元時の、復元前ZIP作成を任意にしました。

変更内容
- 復元を開始すると、まず通常の復元確認を表示。
- 続いて「復元前の現在の端末データをZIPで保存しますか？」と確認。
- OKを選ぶと、従来通り安全用ZIPを作成してから復元。
- キャンセルを選ぶと、復元自体はキャンセルせず、ZIPを作成せずにそのまま復元。
- アカウント画面の説明も「自動退避」から「ZIPで保存するか選べる」へ変更。
- らくらく復元と詳細設定側の完全バックアップ復元は同じ復元処理を利用するため、両方に反映されます。

Supabase側の変更はありません。
GitHubの index.html を上書きしてください。
