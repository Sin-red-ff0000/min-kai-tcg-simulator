みん会TCG Simulator v10.3 PWA版

内容
- index.html : シミュレーター本体
- manifest.webmanifest : PWA設定
- sw.js : オフライン用Service Worker
- icons/ : ホーム画面アイコン

重要
PWA機能は、Documentsなどから index.html を直接開く file:// 方式では動作しません。
HTTPSで公開したURLから一度開く必要があります。

使い方
1. このフォルダの中身を、そのまま同じ階層構成でWebホスティングへアップロードします。
2. iPhoneのSafariで公開URLの index.html を開きます。
3. 共有ボタン → ホーム画面に追加 を選びます。
4. 追加された「みん会TCG」アイコンから起動します。
5. 一度正常に読み込んだ後は、Service Workerのキャッシュによりオフラインでも起動できます。

更新時
新しいバージョンを同じURLへアップロードすると、オンラインで開いた際に最新版の取得を試みます。
古いService Workerキャッシュはバージョン変更時に削除される構成です。

保存データ
カード・デッキはブラウザ/PWA側のlocalStorageへ保存されます。
Documents版など別の環境からは自動で引き継がれません。
移行時はシミュレーター内の「全データをバックアップ」でJSONを作成し、
PWA版で「バックアップから復元」を使ってください。

通常バックアップversion 9以降では、現在の自動保存盤面と名前付きスナップショットもバックアップ対象です。

  - カード

  - カード画像のサムネイル

  - 現在のカード / デッキ / 画像 / 対象設定を置き換える
  - 復元前にバックアップ内のカード数 / デッキ数 / 画像数を確認表示

- ZIP内各ファイルはCRC32で破損チェック
- 画像データベース復元はIndexedDBの1トランザクションで置換

- POWER修正が0以外の時はプレイヤー欄に「ホームPW +xxxx / -xxxx」を表示
- カード詳細のPOWER欄に「元値 / 個別 / ホーム」の内訳を表示

v8.3 緊急修正：コレクション操作不能
- v8.2で追加したカードエフェクト用モーションエンジンの初期化順を修正
- 原因
  - syncFxRuntimePause()を実行した時点で、cardFxMotionRaf等のlet変数がまだ初期化されていなかった
  - アニメーションOFFでも初回起動時にkickCardFxMotionEngine()へ到達し、ReferenceErrorでスクリプト後半が停止する可能性があった
  - その結果、後段にあるコレクション関連処理が正常に利用できなくなる状態が発生していた
- 修正
  - モーション状態変数を最初に初期化
  - 全関数定義後にobserver / visibility処理を起動
  - アニメーション対象が0件ならrequestAnimationFrameループを即終了
  - タブ非表示時はrequestAnimationFrameを明示的にcancel
  - animated DOMが無くなった場合もモーションループを停止
- アニメーション既定OFFはv8.2仕様のまま維持
- 23種の加工寄せ、レイヤー3・4折りたたみも維持
- データ形式・バックアップ形式に変更なし

- スナップショット読込前の現在盤面は自動保存される

- 古いバックアップを復元した場合は盤面保存データなしとして扱う
- 完全バックアップversion 4は維持し、内部の通常バックアップをversion 9へ更新

- 押した時点でキャラクターゾーンに存在し、POWERを持つカードの個別 powerMod へ値を加算

- 反映後は「現在のホームに反映」の入力値だけ0へ戻す

- 後からホームへ出るキャラクターには反映済みの個別補正は付かない
- 反映値の入力途中は盤面のPOWER表示へ影響しない
- 反映値は盤面UI状態として自動保存され、Undo / Redoの対象外
- 盤面リセット時には反映待ちの値を0へ戻す

v11.1 フレーム・エフェクト強化 Phase 2：粒子系エフェクト刷新
- 星屑 / 光粒子 / 蝶光 / 桜吹雪 / 雪華 / 泡沫 / 羽根 / 花吹雪 / 砂塵を重点リファイン
- 粒子の大きさ・透明度・密度を複数段階へ分け、均一なドット模様に見えにくく調整
- 近景 / 中景 / 遠景を意識した粒子レイヤーへ再構成し、カード画像との奥行きを強化
- 星屑：微細な星粒と局所的な強い反射を分離し、全面が白く霞む見え方を抑制
- 光粒子：暖色 / 寒色 / 淡紫の発光粒を混在させ、柔らかい浮遊光へ変更
- 蝶光：鱗粉状の微細反射と淡い回折色を中心に再調整
- 桜吹雪 / 花吹雪：粒径と色のばらつきを増やし、規則的な水玉模様感を軽減
- 雪華：白色粒と青白い微粒子を分離し、冷たい奥行きを強化
- 泡沫：大小のレンズ状リングを混在させ、同じ大きさの泡が並ぶ見え方を軽減
- 羽根：繊維状の反射と疎な明点へ整理し、画面全体を覆いすぎない質感へ変更
- 砂塵：明暗の鉱物粒を混在させ、マットな砂粒 / 金属粉寄りの質感を強化
- アニメーションは種類ごとに移動方向・速度・揺らぎを分離し、粒子群が一枚の画像として動く印象を軽減
- v11.0の光学系エフェクト刷新を維持
- 通常バックアップ / 完全バックアップのデータ形式は変更なし
- Service Workerキャッシュをv11-1へ更新


v11.2 属性系エフェクト刷新
- 炎 / 氷晶 / 雷光 / 水面 / 霧 / 闇のオーラ / 墨染を重点的に再設計
- 炎は下端・外周から立ち上がる熱と火の粉を中心にし、カード画像を覆いすぎない構成へ変更
- 氷晶は結晶面の形成と冷たい反射筋を強化
- 雷光は常時発光ではなく、短い閃光が断続的に走る演出へ変更
- 水面は波紋と水面反射を分離し、ゆっくりした揺らぎへ調整
- 霧は複数のぼかし層が異なる速度で漂う奥行き表現へ変更
- 闇のオーラは中央のカード絵を潰さず、外周へ暗紫色の気配が集まる構成へ変更
- 墨染は単純な黒被せではなく、墨溜まりと滲みの濃淡を再構成
- スマートフォンでは過剰なぼかしと細部を抑えて負荷を軽減
- v11.0光学系 / v11.1粒子系の刷新内容を維持
- データ形式・バックアップ形式は変更なし


v11.3 魔法 / SF系エフェクト刷新
- 魔法陣 / ルーン / 聖光 / 宇宙 / グリッチ / 歯車 / デジタルコードを重点リファイン
- 魔法陣は外周・内周・中心核を分離し、複数リングが異なる速度 / 方向で回る構成へ変更
- ルーンは大きな文字列を貼る見た目を抑え、外周刻印と点灯の強弱を中心に再構成
- 聖光はカード全体の白被りを抑え、上部から差す複数の細い光柱と中心光へ変更
- 宇宙は星粒 / 星雲 / 軌道を独立レイヤー化し、奥行きと緩やかな視差を強化
- グリッチはカード本体を揺らさず、内部のRGB分離 / 走査帯 / スキャン光だけを動かす方式へ変更
- 歯車はUnicode記号中心の表現を減らし、複数径の機械リングとして描画
- デジタルコードは文字の塊から、縦方向のコード列 / 走査光 / 微細ノードへ再構成
- アニメーションはカードレイヤー全体ではなく内部要素を個別に動かし、盤面の安定性を優先
- スマートフォンでは細部と透明度を抑え、可読性と負荷を調整
