みん会TCG Simulator v6.0 PWA版

内容
- index.html : シミュレーター本体
- manifest.webmanifest : PWA設定
- sw.js : オフライン用Service Worker
- icons/ : ホーム画面アイコン

重要
PWA機能は、Documentsなどから index.html を直接開く file:// 方式では動作しません。
HTTPSで公開したURLから一度開く必要があります。

使い方
1. このフォルダの中身を、そのまま同じ階層構成でWebホスティングへアップロードします。
2. iPhoneのSafariで公開URLの index.html を開きます。
3. 共有ボタン → ホーム画面に追加 を選びます。
4. 追加された「みん会TCG」アイコンから起動します。
5. 一度正常に読み込んだ後は、Service Workerのキャッシュによりオフラインでも起動できます。

更新時
新しいバージョンを同じURLへアップロードすると、オンラインで開いた際に最新版の取得を試みます。
古いService Workerキャッシュはバージョン変更時に削除される構成です。

保存データ
カード・デッキはブラウザ/PWA側のlocalStorageへ保存されます。
Documents版など別の環境からは自動で引き継がれません。
移行時はシミュレーター内の「全データをバックアップ」でJSONを作成し、
PWA版で「バックアップから復元」を使ってください。

対戦中の盤面状態はバックアップ対象外です。

  - カード

  - カード画像のサムネイル
  - カードごとの横長 / 縦長画像設定

  をまとめて保存

  - 現在のカード / デッキ / 画像 / 対象設定を置き換える
  - 復元前にバックアップ内のカード数 / デッキ数 / 画像数を確認表示
- ZIP内では同じ画像を複数カードが共有していても画像本体は1回だけ保存

- ZIP内各ファイルはCRC32で破損チェック
- 画像データベース復元はIndexedDBの1トランザクションで置換
- カード画像ストレージの案内を「完全バックアップZIPには画像を含む」に更新

- カード詳細のPOWER欄に「元値 / 個別 / ホーム」の内訳を表示

v5.8 スマートフォン操作：画面端スワイプで戻る
- 設定 > 画面・ナビ > スマートフォン操作 に「画面端を右へスワイプして前の画面へ戻る」を追加
- 初期値はOFF
- テーマ / 画面設定モデルをversion 6へ更新
  - 旧設定は自動移行し、新機能はOFFのまま
  - 完全バックアップversion 3は維持し、themeVersionは6として保存
- ON時のみ、タッチ端末かつ画面幅900px以下で有効
- 画面左端の約28pxだけをジェスチャー開始領域として使用
- 右方向72px以上、かつ横移動が縦移動より十分大きい場合だけ戻る
- 操作中は左端に小さな「戻る」インジケーターを表示
- アプリ内部の画面履歴を最大30件保持
- 最初にHOMEから別画面へ進んだ場合もHOMEを履歴へ保持
- HOMEを履歴の終点として扱い、HOMEではスワイプしても何もしない
- カード詳細などモーダルが開いている場合は、画面移動より先にモーダルを閉じる
- 閉じられないモーダルでは戻る操作を実行しない
- 対戦盤面が存在する状態で他画面へ移動した場合は、履歴から盤面へ戻れる
- 盤面が消滅済みの場合は履歴上の盤面を自動的に飛ばす
- ホームへ通常移動した時は画面履歴をリセット
- カードや盤面の通常ドラッグ領域には触れず、左端だけを専用領域にすることで誤操作を抑制
- 端末 / ブラウザ標準の戻るジェスチャーが優先される環境では、アプリ側のジェスチャーが取得できない場合がある
- 通常バックアップversion 6 / 完全バックアップversion 3を維持
