みん会TCG Simulator v1.3 PWA版

内容
- index.html : シミュレーター本体
- manifest.webmanifest : PWA設定
- sw.js : オフライン用Service Worker
- icons/ : ホーム画面アイコン

重要
PWA機能は、Documentsなどから index.html を直接開く file:// 方式では動作しません。
HTTPSで公開したURLから一度開く必要があります。

使い方
1. このフォルダの中身を、そのまま同じ階層構成でWebホスティングへアップロードします。
2. iPhoneのSafariで公開URLの index.html を開きます。
3. 共有ボタン → ホーム画面に追加 を選びます。
4. 追加された「みん会TCG」アイコンから起動します。
5. 一度正常に読み込んだ後は、Service Workerのキャッシュによりオフラインでも起動できます。

更新時
新しいバージョンを同じURLへアップロードすると、オンラインで開いた際に最新版の取得を試みます。
古いService Workerキャッシュはバージョン変更時に削除される構成です。

保存データ
カード・デッキはブラウザ/PWA側のlocalStorageへ保存されます。
Documents版など別の環境からは自動で引き継がれません。
移行時はシミュレーター内の「全データをバックアップ」でJSONを作成し、
PWA版で「バックアップから復元」を使ってください。

対戦中の盤面状態はバックアップ対象外です。


v1.1 第1段階
- スマホの手札に「スクロール / 操作 / 追従ON・OFF」を追加
- 新規盤面の手札モードはスクロール
- スクロールモードではカード上から横スクロール可能。タップで詳細
- 操作モードでは従来のシームレスドラッグ
- 追従ON時は、外部から手札へカードが加わると追加カードが見える位置へ移動
- 追従設定は端末に保存され、盤面リセット・新規盤面でも維持


v1.2
- 「デッキの中を見る」に検索を追加
  - 名前：部分一致
  - Lv：完全一致
  - 種族：部分一致
  - 効果：部分一致
  - 種類：キャラクター / ルーム / ロール / ルールプラス
- 検索結果は現在の山札順を維持
- デッキ内表示に種族とカード種類を追加
- 効果検索時は一致箇所周辺を短く表示
- 検索結果件数 / デッキ総数を表示
- 手札へカードを移しても、モーダルを閉じるまでは検索条件を維持
- メインデッキ / その他デッキの両方で利用可能
- スマホ手札の追従処理を修正
  - requestAnimationFrame前に追従待ち情報が消えていた問題を修正
  - 追従ON時は追加後の手札末尾までスクロール


v1.3
- 盤面カード名の視認性を優先
  - ズーム100%未満ではカード名だけ逆補正し、極端に小さくならない
  - カード名は最大2行
  - 半透明のネームプレートを追加
  - 小倍率ではLv/POWERを先に省略し、カード名とカウンターを優先
  - レスト中もカード名は正位置で読めるよう逆回転表示
- スマホ手札のスクロールモードでも直接カード移動に対応
  - 横方向は手札スクロール
  - 縦方向はカードドラッグ
- 「デッキの中を見る」に手札へ / 墓地へ / 消失へショートカットを追加
- 墓地・消失一覧に相互移動とデッキ下へのショートカットを追加
- 墓地・消失一覧はPOWERの代わりに種族を表示
