みん会TCG Simulator v8.8 PWA版

内容
- index.html : シミュレーター本体
- manifest.webmanifest : PWA設定
- sw.js : オフライン用Service Worker
- icons/ : ホーム画面アイコン

重要
PWA機能は、Documentsなどから index.html を直接開く file:// 方式では動作しません。
HTTPSで公開したURLから一度開く必要があります。

使い方
1. このフォルダの中身を、そのまま同じ階層構成でWebホスティングへアップロードします。
2. iPhoneのSafariで公開URLの index.html を開きます。
3. 共有ボタン → ホーム画面に追加 を選びます。
4. 追加された「みん会TCG」アイコンから起動します。
5. 一度正常に読み込んだ後は、Service Workerのキャッシュによりオフラインでも起動できます。

更新時
新しいバージョンを同じURLへアップロードすると、オンラインで開いた際に最新版の取得を試みます。
古いService Workerキャッシュはバージョン変更時に削除される構成です。

保存データ
カード・デッキはブラウザ/PWA側のlocalStorageへ保存されます。
Documents版など別の環境からは自動で引き継がれません。
移行時はシミュレーター内の「全データをバックアップ」でJSONを作成し、
PWA版で「バックアップから復元」を使ってください。

対戦中の盤面状態はバックアップ対象外です。

  - カード

  - カード画像のサムネイル
  - カードごとの横長 / 縦長画像設定

  をまとめて保存

  - 現在のカード / デッキ / 画像 / 対象設定を置き換える
  - 復元前にバックアップ内のカード数 / デッキ数 / 画像数を確認表示
- ZIP内では同じ画像を複数カードが共有していても画像本体は1回だけ保存
- 画像のリンク情報はカードID単位で保存され、複製カードの共有関係も復元
- manifest.json + images/ 以下の構成
- カード画像はすでにWebP等で圧縮済みのため、ZIP内部は無圧縮格納方式を使用
- ZIP内各ファイルはCRC32で破損チェック
- 画像データベース復元はIndexedDBの1トランザクションで置換
- カード画像ストレージの案内を「完全バックアップZIPには画像を含む」に更新

v5.8 スマートフォン操作：画面端スワイプで戻る
- 設定 > 画面・ナビ > スマートフォン操作 に「画面端を右へスワイプして前の画面へ戻る」を追加
- 初期値はOFF
- テーマ / 画面設定モデルをversion 6へ更新
  - 旧設定は自動移行し、新機能はOFFのまま
  - 完全バックアップversion 3は維持し、themeVersionは6として保存
- ON時のみ、タッチ端末かつ画面幅900px以下で有効
- 画面左端の約28pxだけをジェスチャー開始領域として使用
- 右方向72px以上、かつ横移動が縦移動より十分大きい場合だけ戻る
- 操作中は左端に小さな「戻る」インジケーターを表示
- アプリ内部の画面履歴を最大30件保持
- 最初にHOMEから別画面へ進んだ場合もHOMEを履歴へ保持
- HOMEを履歴の終点として扱い、HOMEではスワイプしても何もしない
- カード詳細などモーダルが開いている場合は、画面移動より先にモーダルを閉じる
- 閉じられないモーダルでは戻る操作を実行しない
- 対戦盤面が存在する状態で他画面へ移動した場合は、履歴から盤面へ戻れる
- 盤面が消滅済みの場合は履歴上の盤面を自動的に飛ばす
- ホームへ通常移動した時は画面履歴をリセット
- カードや盤面の通常ドラッグ領域には触れず、左端だけを専用領域にすることで誤操作を抑制
- 端末 / ブラウザ標準の戻るジェスチャーが優先される環境では、アプリ側のジェスチャーが取得できない場合がある
- 通常バックアップversion 6 / 完全バックアップversion 3を維持

v8.3 緊急修正：コレクション操作不能
- v8.2で追加したカードエフェクト用モーションエンジンの初期化順を修正
- 原因
  - syncFxRuntimePause()を実行した時点で、cardFxMotionRaf等のlet変数がまだ初期化されていなかった
  - アニメーションOFFでも初回起動時にkickCardFxMotionEngine()へ到達し、ReferenceErrorでスクリプト後半が停止する可能性があった
  - その結果、後段にあるコレクション関連処理が正常に利用できなくなる状態が発生していた
- 修正
  - モーション状態変数を最初に初期化
  - 全関数定義後にobserver / visibility処理を起動
  - アニメーション対象が0件ならrequestAnimationFrameループを即終了
  - タブ非表示時はrequestAnimationFrameを明示的にcancel
  - animated DOMが無くなった場合もモーションループを停止
- アニメーション既定OFFはv8.2仕様のまま維持
- 23種の加工寄せ、レイヤー3・4折りたたみも維持
- データ形式・バックアップ形式に変更なし

- アニメーション時は透明レンズ面の反射だけが変化

羽根
- 羽根そのものではなくパール繊維エンボス / サテン紙調ラミネートへ変更
- 斜交する細い繊維線で柔らかな光沢を表現
- アニメーション時は繊維面の光沢位置のみ変化

花吹雪
- 花びらの絵ではなく多色マイクロコンフェッティコールドフォイルへ変更
- 桃 / 紫 / 橙 / 水色の極小箔片を低密度で配置
- アニメーション時は多色箔の見え方だけが変化

砂塵
- 砂嵐ではなく粗粒メタリックマット / 鉱物粒子箔へ変更
- 茶金 / 淡金 / 暗褐色の微細粒子を重ねる
- アニメーション時はマット粒子の鏡面成分だけが緩やかに変化

共通
- 大きなモチーフをカード上に描く方式を使用しない
- v8.3のrequestAnimationFrameモーションエンジンを維持
- v8.4 / v8.5で個別再設計した10種を維持
- アニメーション既定OFFを維持
- レイヤー3・4折りたたみを維持

v8.7 カードエフェクト個別再設計 後半 / 全30種仕上げ
対象：霧 / 闇のオーラ / 墨染 / グリッチ / 歯車 / デジタルコード

霧
- 霧そのものを描かず、フロストマットラミネート / 半透明ソフトタッチ加工へ再設計
- 微細な曇り目と低コントラスト反射で曇りガラス状の表面を表現

闇のオーラ
- 煙やオーラのイラストを使わず、黒紫オイルスリック / 周辺スポットUVへ再設計
- 中央のカード絵を潰さず、外周側ほど濃い特殊ニスに見える構成

墨染
- 墨飛沫ではなく墨黒スポットグロス / 墨流しラッカーへ再設計
- 黒の濃淡と部分光沢を中心にした表面加工

グリッチ
- 壊れた画面表現を減らし、RGB回折セキュリティホロへ再設計
- 赤 / 水色 / 紫の微細な線と反射帯で偽造防止箔のような質感

歯車
- 歯車の大きな絵ではなくエンジンターン / ギヨシェ機械彫刻へ再設計
- 大小2つの微細円刻印を金属面として表示

デジタルコード
- 落下文字を使わず、回路エッチング / PCBセキュリティホロへ再設計
- 回路線と極小発光ノードを加工として配置

全30種の最終調整
- エフェクト描画DOMに有効レイヤー数1〜4を明示
- 2 / 3 / 4レイヤー重ね時の自動濃度調整を追加
- レイヤー数が増えるほど後方レイヤーを段階的に抑えて白飛びを防止
- アニメーション反射も多重レイヤー時は自動的に弱める
- 「弱 / 標準 / 強」の差を再調整
  - 弱：不透明度と細部を明確に抑える
  - 標準：従来基準
  - 強：単純な白飛びではなく彩度 / 密度 / コントラストを少し上げる
- Collectionの小さな一覧表示は少し控えめ、Viewer / 詳細 / 盤面詳細は加工密度を維持
- スマホの3 / 4レイヤー時は後方レイヤーをさらに軽量化
- 高コストblurを再度縮小

モーション安定化
- コレクションで画面外へ出てrequestAnimationFrameが停止した後、再び画面内へ入った時に自動再開する処理を追加
- IntersectionObserverの入画時にkickCardFxMotionEngine()を実行
- アニメーション対象が無い場合はモーションループを停止
- アニメーション既定OFFは維持
