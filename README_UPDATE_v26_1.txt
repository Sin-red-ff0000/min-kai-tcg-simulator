みん会TCG Simulator Ver 26.1

オンライン対戦で再接続した際、デッキ枚数・その他デッキ枚数などが
対戦開始時寄りの値へ戻ってしまう問題を修正しました。

今回確認できた原因
- 再接続時は makePlayer() で選択デッキを一度「対戦開始時の全枚数」で作り直していた。
- 手札は専用復元時にデッキから差し引いていた。
- しかし、キャラクター / 墓地 / 消失 / ペインカウント / ルーム / ルールプラスへ
  既に移動したカードは、盤面へ復元されてもローカルのデッキ側から差し引かれていなかった。
- そのため、再接続後だけ同じカードが「盤面とデッキの両方」に存在する状態になり、
  デッキ枚数が増えたように見えることがあった。
- その他デッキも所有者専用キャッシュ対象外だったため、再接続すると初期状態へ戻る経路があった。

Ver26.1の修正
- 再接続後、手札以外にもキャラクター / 墓地 / 消失 / PC / ルーム / RPへ出たカードを
  ローカルの影デッキから1枚ずつ差し引く。
- 最終的なメインデッキ残り枚数はSupabase/サーバーの deckCount を絶対の正として表示。
- プレイヤー上部の「デッキ○枚」とデッキゾーンの枚数表示をサーバー値へ統一。
- privateStateへ記録するdeckCountもサーバー値を優先し、再接続直後の誤ったローカル枚数を使わない。
- 所有者専用キャッシュへ「その他デッキ」も追加し、再接続で初期枚数へ戻らないよう修正。
- Ver26.1以前のキャッシュから復帰した場合は、RP等へ移動済みのカードをその他デッキから差し引く補正を追加。
- 影デッキのカード内訳を完全に復元できないケースでも、残り枚数はサーバー値を正として維持。
- サーバードローで影デッキ内に該当IDが見つからない場合でも、サーバー枚数表示がずれないよう補正。
- Ver26.0のスクロール・再描画根本修正をそのまま維持。

Supabase Edge Function / SQLの変更はありません。
GitHubの index.html を上書きしてください。
