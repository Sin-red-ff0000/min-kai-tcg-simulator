# みん会TCG Simulator Ver27.2 GitHub更新用

## 更新するファイル

Ver27.1以降は次の3ファイルをGitHubリポジトリのルートへ配置してください。

- index.html
- sw.js
- manifest.webmanifest

index.htmlをVer27.2へ上書きしてください。
sw.js / manifest.webmanifestもZIP内のものをそのまま配置して構いません。

## 修正1：設定専用UI

「機能ガイド」と「診断・メンテナンス」が他画面にも出ていた問題を修正しました。
Ver27.2では設定画面内でのみ表示されます。

## 修正2：1人用オンライン動作確認

ローカル確認は相手がいなくても動作します。

手順：
1. デッキを1つ以上作成
2. オンライン画面を開く
3. 1人用オンライン動作確認を開く
4. ローカル確認を選択
5. P1 / P2 / 観戦を選択
6. 動作確認を開始

SELFTESTという一時ルームが端末内だけに作られ、オンライン対戦盤面へ移動します。
終了するとテストルームを削除し、元の画面へ戻ります。

ローカル確認はSupabaseへ書き込みません。
