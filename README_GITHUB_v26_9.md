# みん会TCG Simulator Ver26.9 GitHub更新用

## 更新方法

ZIP内の `index.html` を、GitHubリポジトリ
`min-kai-tcg-simulator` のルートにある `index.html` へ上書きしてください。

Supabase側の追加作業はありません。

## Ver26.9の主な変更

オンライン対戦に公開情報欄を追加しました。

公開される対象:
- コイントス結果
- ダイス結果
- 手札から選ばれたカード
- 指定カード群から選ばれたカード
- プレイヤーが公開を選んだ「山札の上からN枚」の確認結果

山札確認は自動公開しません。
オンラインの上からX枚確認画面で
「確認したカードを公開情報へ表示」を押した場合だけ共有されます。

公開情報は履歴ではなく、P1/P2それぞれ直近1件だけです。
自分の結果は公開情報欄から消去できます。

観戦者の場合:
- P1/P2の操作ツールを隠します
- 墓地 / 消失一覧は閲覧できます
- ペイン / ルーム / ルールプラスの折りたたみは利用できます
- 公開情報欄はP1/P2双方のものを確認できます

## 動作確認

P1 / P2 / 観戦視点を切り替えて公開情報の見え方を確認できます。
