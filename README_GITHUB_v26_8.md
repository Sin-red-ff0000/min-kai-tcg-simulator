# みん会TCG Simulator Ver26.8 GitHub更新用

## 更新方法

このZIP内の `index.html` を、GitHubリポジトリ
`min-kai-tcg-simulator` のルートにある `index.html` へ上書きしてください。

Supabase側の追加作業はありません。
Ver26.7で追加した `minkai-public-sets` はそのまま使用します。

## Ver26.8の主な変更

オンライン画面に1人用の動作確認機能を追加しました。

- P1視点
- P2視点
- 観戦視点

を1人で切り替えて確認できます。

ローカル確認では、通常対戦ルームへ余計な書き込みをせず表示や秘匿状態を確認します。

実通信確認では、先に通常のオンラインルームを1つ作成しておくことで、
そのSupabaseルームを読みながら1人で各視点を確認できます。

また、オンライン診断情報を表示・コピーできるようにしました。
残りデッキ枚数が0になる問題について、以下を同時に確認できます。

- room.p1 / p2 の deckCount
- room.p1 / p2 の deckTotal
- publicState.p1 / p2 の deckCount
- publicState.p1 / p2 の handCount
- 実際に画面へ採用される deckCount
- revision
- 現在の確認視点

管理キーや手札内容、カード内容などの秘匿情報は診断文へ含めません。

## 確認してほしい箇所

1. オンラインルームを1人で作成
2. 1人用オンライン動作確認を開く
3. P1 / P2 / 観戦を順番に切り替える
4. 各視点で手札などの秘匿状態を確認
5. 墓地・消失の一覧が観戦視点でも開けるか確認
6. 残りデッキ枚数が0になる状態で「診断情報をコピー」
7. その診断結果をバグ報告時に添付

## バージョン方針

Ver27.1到達時にもGitHub更新用READMEを同梱します。
