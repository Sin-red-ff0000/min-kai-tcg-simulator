みん会TCG Simulator Ver 26.2

アカウント画面を分かりやすく整理しました。

主な変更
- ログイン後の最上部に「かんたんクラウド保存」を追加。
- 「らくらくバックアップ」ボタンを追加。
  今のカード・デッキ・カード画像・背景・フレーム・自作エフェクト・外観設定をまとめてクラウドへ保存します。
- 「らくらく復元」ボタンを追加。
  同じアカウントで保存したクラウドバックアップを現在の端末へまとめて復元します。
- らくらくバックアップ／復元は、既存の完全バックアップ機能と同じ安全な処理を利用しています。
- 復元前には現在の端末状態をZIPとして自動退避します。
- 保存済み／未保存／確認中などの状態を、かんたん操作欄でも確認できるようにしました。
- 「この端末でバックアップ → 別端末で同じアカウントへログイン → 復元」という3手順を画面内に表示。
- ログインしただけではデータが勝手に同期・上書きされないことを明記。
- 従来のカード・デッキ同期、差分確認、履歴、完全バックアップは削除せず「詳しいクラウド管理」の中へ整理。
- アカウントとオンライン対戦のルーム参加情報は別物であることを明記。
- クラウド完全バックアップのメタ情報にVer26.2を記録。

Supabase側の変更はありません。
GitHubの index.html を上書きしてください。
