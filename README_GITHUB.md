# みん会TCG Simulator Ver27.7 GitHub更新用

## 更新ファイル

GitHubリポジトリのルートへ以下3ファイルを上書きしてください。

- index.html
- sw.js
- manifest.webmanifest

sw.jsはキャッシュ名をv27-7へ更新しているため必ず上書きしてください。

## 機能ガイド

独立していた「説明」画面は廃止しました。

現在は
⚙設定 → 機能ガイド
から確認できます。

Simulatorに追加してきた便利機能を、カード・デッキ・盤面・オンライン・公開所・アカウント・スマホ・設定に分けて詳しく説明しています。

## 設定エラー修正

設定を操作するたびに
「画面処理中にエラーが発生しました」
と表示される問題について、設定変更時の非同期背景処理と重複イベント登録を修正しました。

特に、
- 背景画像取得
- 背景プレビュー取得
- 設定のリアルタイム反映
- 設定画面再描画

で発生したエラーをアプリ全体の未処理エラーへ流さないよう変更しています。

## Supabase

変更ありません。
