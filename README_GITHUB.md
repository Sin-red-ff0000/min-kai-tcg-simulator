# みん会TCG Simulator Ver27.3 GitHub更新用

## 更新ファイル

GitHubリポジトリのルートへ、ZIP内の次の3ファイルを配置してください。

- index.html
- sw.js
- manifest.webmanifest

今回は `sw.js` も必ず上書きしてください。
Service Workerのキャッシュ名を `minkai-tcg-v27-3` へ変更しています。

## 重要：Ver27.3で直した原因

1人用オンライン動作確認のボタンイベントが、アプリ本体とは別スコープのscriptから登録されていました。

そのためブラウザ上では
`onlineSelfTestStart is not defined`
相当のエラーになり、ボタンへイベント自体が付いていませんでした。

Ver27.3ではイベント登録をアプリ本体と同じIIFE内へ移しています。

## 更新後の確認

GitHub Pages更新後は古いService Workerを避けるため、

1. ページを開く
2. Ver27.3になっていることを確認
3. 1度再読み込み
4. まだ旧表示ならブラウザを閉じて再度開く

を行ってください。

その後、

1. デッキを1つ以上作成
2. オンライン画面
3. 1人用オンライン動作確認
4. ローカル確認
5. P1視点
6. 動作確認を開始

でSELFTEST盤面へ移動します。

開始に失敗した場合、今度は「動作確認の開始に失敗しました：○○」と具体的なエラーを画面に表示します。
