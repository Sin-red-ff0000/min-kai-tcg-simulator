# みん会TCG Simulator Ver27.5 GitHub更新用

## 更新ファイル
以下3ファイルをGitHubリポジトリのルートへ上書きしてください。

- index.html
- sw.js
- manifest.webmanifest

sw.jsはv27-5キャッシュへ更新しているため必ず上書きしてください。

## 1人用オンライン動作確認
Ver27.5では、オンライン盤面の見た目を使いつつ、ローカル確認の操作処理は通常盤面と同じ方式へ変更しました。

P1視点：P1側を操作可能
P2視点：P2側を操作可能
観戦視点：双方閲覧専用

カード移動、詳細、表裏、レスト、カウンター、マーカー、手札、デッキ等をSELFTEST内で操作できます。

## P1/P2デッキ設定
動作確認欄でP1/P2それぞれについて
- メインデッキ
- その他デッキ
- 最推し
を選べます。

P1とP2に異なるデッキを設定して、相手側・観戦側からの見え方を1人で確認できます。
